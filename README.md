# ETL-Project-Web-scrapping-financial-data
A school project that can serve as an introdoction to Data Engineering !

This project aims to introduce two essential pillars of data-related professions: 
**The ETL process** ( Extract - Transform - Load ), which is fondamental to Data Engineering
**The responsible use of AI** which as become a central tool in data manipulation and analysis.

We designed a mini automated data-processing pipeline, rom extracting data from the web ( Extraxt), through transforming it ( Transform), to exporting it into different formats ( Load:CSV,XLSX, etc.)

This project also allowed me to explore how AI can help you generate code while developping a critical perspective on its uses, limiations and ethical and environmental implications.
